Question 7: What is the difference between DNS and DHCP?问题 7：DNS 和 DHCP 有什么区别？

Suggested answer:建议答案：

“DHCP automatically provides devices with network settings such as an IP address, subnet mask, default gateway and DNS server addresses. DNS translates hostnames, such as a server name, into IP addresses.“DHCP 会自动为设备提供网络设置，例如 IP 地址、子网掩码、默认网关和 DNS 服务器地址。DNS 将主机名（例如服务器名称）转换为 IP 地址。

When troubleshooting, I would use ipconfig /all to verify the device’s IP configuration, gateway and DNS servers. I could use ipconfig /renew for a DHCP lease issue and nslookup to test DNS resolution. I would also compare whether the resource works by IP address but not by hostname, because that often indicates a DNS problem.” Microsoft’s troubleshooting guidance similarly recommends checking IP configuration and using nslookup to isolate DNS failures. 进行故障排除时，我会使用 `ipconfig /all` 命令来验证设备的 IP 配置、网关和 DNS 服务器。对于 DHCP 租约问题，我可以使用 `ipconfig /renew` 命令，并使用 `nslookup` 命令来测试 DNS 解析。我还会比较资源是否可以通过 IP 地址访问，但无法通过主机名访问，因为这通常表明存在 DNS 问题。微软的故障排除指南也建议检查 IP 配置并使用 `nslookup` 命令来隔离 DNS 故障。Microsoft Learn+2
